# 长卷 1.1.3（Build 46）发布文案

## 此版本的新增内容

- 改善横向表格拼接，增强冻结列、重复列及小幅上下偏移场景的对齐稳定性。
- 修复冻结列边缘的残留文字导致横向整理失败的问题，优化位移计算效率。
- 底部内容始终被悬浮按钮遮挡时，在可确认完整行边界的情况下生成可用长图，并明确提示「底部遮挡行未收录」。
- 此类部分结果保留原始画面，直到手动清理；不生成未拍到的内容，不静默跳过中间缺口。
- 保留原有纵向与双向滚动、跨页接续、状态栏选项、中英文界面及完成预览。

## 发布范围

2026-10-20 实时回读 App Store Connect：1.1.2（42）已可分发，因此本轮新建 1.1.3（46），不替换已公开版本。Build 46 与已安装的 Build 45 功能源码一致，仅提高版本号和构建号。安装、自动回归、用户重新录制验收、上传、审核提交与公开发布分别记录。
