# App Review notes — 1.1.6 (63)

Long Scroll stitches long screenshots on an iPhone running iOS 27 or later. The capture test can be completed without signing in to an account.

1. In Long Scroll settings, choose vertical stitching and turn on “保留状态栏” / “Keep Status Bar”.
2. Open a full-screen scrollable app with a fixed top navigation bar. Start “长卷” / “Long Scroll” from Control Center, choose “Share Entire Screen” in the system panel, and start scrolling as soon as the expanded Dynamic Island collapses. Scroll continuously with overlapping content.
3. Touch and hold the Dynamic Island and tap “完成” / “Finish”, or tap the main Long Scroll control in Control Center again. Allow add-only Photos access if prompted. Open the long screenshot in Photos or in the app preview.

The saved image should retain the opening content and show a clear time, battery indicator, Dynamic Island, and separate recording dot. The app uses a later original status strip when it can verify the status background and navigation match the opening.

Privacy behavior is unchanged from 1.1.5. Capture and stitching run on the device. Optional feedback uses a mail draft with the user's description and any diagnostics they choose to include. The privacy policy is at Home → “查看使用方法” / “How to use” → “隐私政策” / “Privacy policy”.
