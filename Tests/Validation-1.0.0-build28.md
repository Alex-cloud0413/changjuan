# Build 28 — 真机反馈修正

日期：2026-10-06。最低 iOS 27，版本 1.0.0。只更新用户连接设备，不发布 App Store 或公开 OTA。

## 起始遮挡与入口

- 不能承诺阻止系统自动展开或设置收起时长。操作行新增「等面板收起再滚动」；初次与重复使用引导均要求等待期间停在起始位置，避免丢失从未清晰采集的内容。
- 收起状态改为「长按操作／长按继续」，展开行说明可长按灵动岛接页。保留同一个实时活动，不在收起后删除接页按钮。
- 新增可选控制中心控制「长卷 · 接下一页」。采集中暂停、切换后继续，不打开主 App；非采集中禁用。两个控制仅在状态变化时刷新，不再随每个采集帧重复刷新。
- 生产 SwiftUI 行渲染的正常与辅助功能大字号均已目视检查；不是系统灵动岛容器或真实收起时长测试。

## 重叠原因与修复证据

- 在用户提供的 1206×7083 附件所对应的 49 帧录制上，原实现可复现相同半行文字重叠。
- 第 22→23 帧实际向下移动，粗匹配因重复文字卡片结构选中相反方向，旧精校准采用 -538 像素，得分约 10.20。
- 新实现在首次精校准较弱时验证另一个方向，得到正确 +728 像素，得分约 0.040。高质量匹配仍走原来的单次精校准快速路径；质量不足的位移不强行接入。
- 同一组原始帧的新结果为 1206×8349；多出的 1266 行是错误方向此前漏掉的内容，不是简单放大或重复插入。已检查「大家如何看待影视飓风」附近无重复半行，后续内容按正常顺序衔接。
- 真实夹具复算断言 `--expect-edge 22 23 728` 通过。隔离模拟器接缝组装约 0.30 秒；这不是用户刚结束录制时的真机冷态耗时，不能据此承诺整体耗时。
