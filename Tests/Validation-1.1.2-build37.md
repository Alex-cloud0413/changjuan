## 设计与实现

按用户指定的 Apple Design skill 审查现有运行界面，以默认首页不增加说明性组件为约束：只加右上角齿轮（44×44 pt），打开原生设置 sheet。方向用分段选择，状态栏用开关，清理独立分组。普通字号一屏展示；辅助功能字号切换为原生方向列表，允许设置页滚动，不缩小文字。默认仍为纵向、去状态栏；横向模式才显示简短模式提示。

这是运行截图自查，不是独立设计师审查。两项发现已修正：系统 confirmationDialog 在此运行环境将取消隐藏为点击外部，改为有明确「取消／清理缓存」的原生 alert；分段按钮在辅助功能字号下文字仍小，改为 inline picker。采用系统交互而非自绘选项，参照 [Apple Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts) 与 [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)。

- 方向和状态栏偏好在录制开始时写入 manifest，旧 manifest 缺省保持纵向/裁切；修改偏好不会重解读旧记录。缓存增加可选轴/采样宽度字段，旧纵向缓存兼容，错轴缓存拒绝并重算。
- 横向只转置用于匹配的视图，最终直接从原始 JPEG 以 1:1 比例合成，输出 JPEG 参数保持 0.94。为密集表格增加横向采样细节，支持左右反向、往返和手动跨页；顶部/底部不移动的栏在每段中保留一次。匹配没有放松原有纵向参数。
- 状态栏开启时保留真实像素，可能包含录制指示。横向宽图只在左上方出现一次；不重复、不拉伸、不伪造时间/电量。展开遮挡的录制面板仍排除。
- 手动清理只处理可确认归属、无符号链接的录制原始 JPEG 与 Analysis-v1。包括失败/未保存输入，执行前写清理标记，防止异常恢复和迟到分析重建。保留 Outputs、Photos 和偏好；未知/损坏记录保留并报告未完全清理。
- 清理前提示不可撤销及失去重新整理能力；录制、选择共享、整理和清理期间禁用修改及清理。后台 utility 执行，不阻塞主线程。

## 真机验收门槛

1. 原位升级，不卸载。确认默认纵向/去状态栏不变，两个偏好切换、关闭 App 后保持；从控制中心开始也采用新偏好。
2. 在真实表格里向右、向左、来回移动，检查列号/金额无重复遗漏；验证冻结列、固定工具栏及多个分段。一次只沿一个轴，不能横竖混合、斜移或中途转屏。大片空白、完全重复列、极窄表格及复杂冻结区域可能无法可靠匹配，不承诺所有第三方 App 成功。
3. 分别开关状态栏，检查实际时间/信号/电量、灵动岛展开遮挡及横向结果；看宽图能否自然横向拖动、缩放、在多张输出之间换页。
4. 测试录制中设置禁用、清理取消、空缓存提示、失败录制确认清理、重新打开不会误恢复，检查相册与已生成预览仍在。只有用户明确确认才测试删除失败原始数据。
5. 验证屏幕阅读、实际大字体滚动、冷启动、通知预览、输出画质和多页实际耗时。验收后另行授权 GitHub / App Store 操作。
