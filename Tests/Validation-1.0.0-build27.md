# Build 27 — 顶部遮挡、双向滚动与手动跨页

日期：2026-10-06。版本 1.0.0，最低 iOS 27.0。仅供连接设备试用，不上传 App Store、不更新公开 OTA 页面。

## 实现范围

- 灵动岛正常字号改成一行动作，移除持续变化的帧数；保留「完成」，新增「接下一页／继续」。辅助功能大字号自动分行，按钮最小内容高度 44 pt。系统展开时长不可由 App 设置。
- 本地检查黑红展开区域及共享系统面板。被遮内容优先使用后续清晰画面，无法恢复未曾清晰采集的内容。OCR 仅用于候选共享面板，并以共享按钮文字确认，不对所有普通画面运行。
- 同页位移改为带方向估计，复用稀疏像素级精校准，按空间坐标拼接并合并重复覆盖，不按录制时间重复追加。
- 跨页必须先暂停、切换、再继续。暂停采集但不停止系统共享；恢复点写入可选 `segmentStarts`，旧记录仍可读取。跨页顺序保留，使用细分隔带，不伪造连续页面。
- 保留原始帧，不增加固定首尾等待，也不更改照片保存和通知预览机制。

## 真机验收

1. 控制中心启动，确认共享后立即缓慢滚动，确认结果不保留启动展开区域。若遮挡后直接滚走且没有回到那段内容，确认结果没有伪造隐藏文字。
2. 多行文字页面分别向下、向上、上下往返；检查顶部起点、底部终点、接缝重叠与重复段。
3. 页面 A 滚动 →「接下一页」→ 切换到 B →「继续」→ 滚动 →「完成」。检查 A/B 次序、分隔带和切换界面未被收进结果；也测试 B 仅停留不滚动。
4. 暂停后直接完成；连续空切换；回 App 后再恢复。确认可完成且状态不乱。
5. 比较同长度单页与旧版本整理时间，检查照片保存、通知缩略图和点击预览仍正常；专注模式可能抑制横幅。

安装与用户验收是独立状态：仅安装成功不代表上述真实页面场景已验收。
