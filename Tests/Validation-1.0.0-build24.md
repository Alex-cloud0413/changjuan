# Build 24 — 文字接缝精度修复

日期：2026-09-07。用户在 Build 23 真机长图中发现，拼接缝偶尔穿过文字行并重复数个像素，使文字看起来发生重叠。

## 原因与修复

- 原算法用 72 像素宽的等比例灰度缩略图估算滚动距离；缩略图的一个纵向像素会对应原图多个像素，换算回原图时会产生可见的取整误差。
- 保留原有快速粗匹配，用于选择有效滚动区间和过滤重复、模糊画面。
- 只对准备采用的相邻画面按需生成“保留原始纵向分辨率、压缩横向分辨率”的灰度图，在粗估值附近做窄范围精校准。
- 精校准无法形成可信接缝时跳过该帧，避免把不确定的接缝画进文字；后续画面仍可与上一张可靠画面继续匹配。
- 捕获、控制中心入口、灵动岛完成、保存和通知流程均未改动。

## 已完成验证

- OverlapEstimator 8 项检查通过，新增用例可将 143 像素附近的粗估值恢复为真实的 137 像素。
- iPhoneOS 27 SDK 对拼接相关生产代码类型检查通过。
- iOS 26.5 模拟器上的生产 JPEG 拼接回归 4 项通过：无关首尾画面不进入结果、短录制不被误删、静止画面仍被拒绝、像素级精度用例通过。
- 像素级精度用例中，原粗匹配会把每次 217 像素移动换算为约 219 像素；新算法输出总高度严格为 1,391 像素，4 帧全部采用，处理耗时约 0.035 秒。
- Xcode 27 beta、iOS 27 SDK、Release、无签名完整构建通过。

## 仍需真机验收

- 用包含多行文字的微信、小红书或网页内容重复截取，检查所有文字行是否不再重叠。
- 再用双列商品流验证动态图片、悬浮条存在时没有新增断层或漏行。
- 对比 Build 23 与 Build 24 的结束到保存耗时，确认精校准没有造成体感变慢。

## 真机结果

- 用户确认文字重叠已消失。
- 76 个原始画面中采用 43 个，整理耗时 11.9456 秒；上一版相近的 71 帧用时 5.4420 秒。
- 结论：精度修复有效，但全画面逐候选扫描造成明显性能回退，由 Build 25 继续优化。
