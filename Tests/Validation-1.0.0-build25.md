# Build 25 — 快速像素级接缝校准

日期：2026-09-07。目标是在保留 Build 24 文字不重叠效果的同时，消除其约 6.5 秒的额外精校准耗时。

## 改动

- 粗匹配、有效画面选择和原始纵向分辨率均保持不变。
- 精校准不再为每个候选位移完整扫描全部像素；改为遍历分布式稀疏网格，并对有文字或边缘、且明确支持页面移动的区域做稳健投票。
- 固定按钮、悬浮条和既不匹配移动位置也不匹配固定位置的动态内容不参与接缝决策。
- 精校准仍以一行源像素为步长，未降低纵向精度。
- 完成诊断新增采样、滚动区间选择、接缝组装和渲染四个阶段的独立耗时，便于后续真机定位。

## 已完成验证

- OverlapEstimator 9 项检查通过，包括 137 像素精确恢复和固定覆盖层干扰用例。
- 生产 JPEG 拼接回归 4 项通过；217 像素移动仍生成严格 1,391 像素总高度，无关首尾画面与短录制行为未回退。
- 模拟器精度用例处理耗时由 Build 24 的约 0.0354 秒降至约 0.0306 秒。
- 模拟 1,927 行纵向分辨率、43 个接缝的独立精校准基准耗时约 0.0882 秒。

## 仍需真机验收

- 重复 Build 24 的多行文字测试，确认无重叠、无断层。
- 读取新的分阶段耗时；以相近 70 至 80 帧录制为例，整理总耗时应明显低于 11.95 秒并接近 Build 23 的约 5.44 秒。

## 首次真机性能结果

- 47 个原始画面中采用 17 个，整理总耗时 4.1983 秒。
- 分阶段：采样 2.1314 秒、滚动区间选择 0.1634 秒、接缝组装 1.2227 秒、渲染 0.6809 秒。
- 相比 Build 24 的 11.9456 秒，本次绝对耗时下降约 64.9%；按原始帧数折算，每帧整理开销下降约 43.2%。
- 文字是否仍无重叠或断层等待用户肉眼确认；确认前不替换公开安装页上的 Build 24。
