# 0.4.4 真机性能与输出验证

2026-09-06，在同一部已连接的 iPhone 17 上，用同一个已完成录制的 41 个画面进行测量。测试只写入独立的 App Documents 测试目录，不修改原录制，也不调用照片保存。

| 阶段 | 0.4.3 算法 / Debug | 0.4.4 算法 / Release |
| --- | ---: | ---: |
| 读取、缩小画面 | 0.452 秒 | 0.530 秒 |
| 确定滚动序列 | 7.789 秒 | 0.034 秒 |
| 计算拼接切片 | 3.317 秒 | 0.011 秒 |
| 渲染、JPEG 编码与文件写入 | 0.204 秒 | 0.173 秒 |
| 整理总耗时 | 11.761 秒 | 0.748 秒 |

这是优化构建与复用计算共同带来的端到端整理结果，不能将加速全部归因于算法改动。也不包含系统结束共享、相册写入或实时活动刷新所需时间。其他长度、机型、系统负载下耗时会不同。

第二次优化版真机复测总耗时 0.792 秒，同样采用 18 帧、略过 23 帧，输出尺寸不变。已查看真机渲染的自定义符号预览，三笔标志形状正确。日常 Release 0.4.4（Build 12）已安装并读回版本，编译产物不含性能测试启动参数，控制中心入口仍为后台模式。

两次都采用 18 帧、略过 23 帧。原输出为 1206 × 6764；裁掉顶部状态栏后为 1206 × 6568。旧录制没有安全区域元数据，验证使用兼容裁剪比例；新录制优先记录窗口安全区域及状态栏高度。

`InspectStitchOutput.swift` 把旧结果按相同高度裁剪后比较 RGB：平均差异 0.647 / 255，仅 0.012% 通道差异超过 12，符合 JPEG 重新编码误差；内容没有因加速缩短或位移。已目视检查应用导航、正文和底部均保留，顶部灵动岛已移除。

控制中心使用 `LongJuanCapture` 自定义符号资源，Xcode 校验通过，真机 `UIImage.isSymbolImage == true`。形状沿用现有 App 图标，系统负责单色着色。系统面板的真实点击与新录制仍需在真机日常使用中验收。

已有的 7 类拼接回归检查通过，包括已知滚动距离、静止页面、大距离滑动、动态商品、固定遮挡、变化横幅与 App 切换前奏。

开发者可用额外编译条件 `LONGSHOT_BENCHMARK` 与启动参数 `--benchmark-latest` 重复测量；该入口不包含在日常 Release 构建中。共享 LongShot Scheme 默认使用 Release 运行，避免把未优化的逐像素计算交给日常用户。
